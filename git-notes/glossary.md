# Glossary

- **Commit** — a snapshot of the working tree with a message and parent pointers (Ch 1).
- **Branch** — a movable pointer to a commit; cheap and disposable (Ch 2).
- **Rebase** — replaying commits onto a new base to keep history linear (Ch 3).
- **Squash** — combining several commits into one before merging (Ch 3).
- **Fast-forward** — moving a branch pointer forward when no divergence exists (Ch 2).
- **Force-with-lease** — a guarded force push that fails if the remote changed underneath you (Ch 3).
- **Working tree** — the files you actually edit on disk.
- **Staging area** — the index; what will go into the next commit.
- **HEAD** — the commit currently checked out.
