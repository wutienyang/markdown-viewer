# Effective Git

A compact set of field notes on using Git well. This is a **sample book** that
demonstrates the markdown reader: chapters, a cheatsheet, and a glossary.

> Good version control is a habit, not a tool. The commands below only matter
> if the surrounding workflow is consistent.

## How to read this

- [Cheatsheet](cheatsheet.md) — commands at a glance
- [Glossary](glossary.md) — terms used throughout
- [Ch 1 · Writing Good Commits](chapters/ch01-commits.md) — the single most important habit
- [Ch 2 · Branching Strategies](chapters/ch02-branching.md) — trunk-based vs Git Flow
- [Ch 3 · Rewriting History](chapters/ch03-history.md) — rebase, squash, and when not to

## Core principle

Make history tell a story. A stranger should be able to read the log top-to-bottom
and understand *what* changed and *why* — without ever opening the diff.
