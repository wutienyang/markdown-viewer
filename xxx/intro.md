## How to add a book

1. Create a new folder (e.g. `my-book/`).
2. Drop your `.md` files inside.
3. Copy `index.html` from another book and edit `window.BOOK_CONFIG` to list your files.

## Format

`docs` is an array of `{ path, title, group, num?, desc? }`. Each entry appears in the sidebar.
